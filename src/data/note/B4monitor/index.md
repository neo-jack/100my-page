---
title: 前端监控
---

轻量前端监控项目，支持真实页面事件的采集、存储与查询。页面接入 SDK 后，可以在管理台查看 JavaScript 异常、资源加载失败、接口请求、Web Vitals 和会话时间线，用于将页面异常定位至具体事件与版本。

## 从页面事件到问题记录

SDK 收集事件后批量发送，失败时退避重试，页面离开时尽力补发。接收服务保存到 SQLite，管理台按项目、环境和版本等条件查看数据，也可以标记问题已解决。

3D 主页只在正式域名下上报生产数据，版本跟随发布提交。SDK 异步加载，不阻塞主页面；它尚未就绪时发生的事件可能遗漏。

## 指标需要结合场景理解

LCP、INP、CLS 等指标取决于浏览器支持和真实访问过程。未发生交互的访问可能不产生 INP；标签页会话也不等于独立用户数。

当前实现会移除 URL 的查询与 hash，不采集输入内容、Cookie 或 DOM 正文。监控台公开可访问，因此接入时仍需检查事件内容是否适合公开。

当前采用单机轻量方案，未提供 DOM 回放、source map 符号化或告警推送。实际数据可通过以下入口查看。
