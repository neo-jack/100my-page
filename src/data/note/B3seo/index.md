---
title: SEO 优化
---

Next.js 等框架可通过服务端渲染或静态生成，提前将页面内容与 SEO 信息写入 HTML，便于搜索引擎读取。

本站采用 React + Vite，借鉴构建期生成的方式，在打包阶段将必要的 SEO 信息写入 HTML，避免依赖浏览器执行 JavaScript 后再补充。

Vite 构建时注入页面标题、描述、规范链接、社交分享信息，以及作者与作品集的结构化数据，同时生成 `robots.txt` 和 `sitemap.xml`，使搜索引擎能够直接读取站点身份与展示主题。

当前实现为元信息注入，不等同于整页 SSR 或 SSG，作品正文尚未预渲染。
