---
title: 界面元素选择器
---

业务开发中，向 AI 描述页面问题通常需要手动复制网页信息并说明修改位置；定位源码则需要在编辑器中搜索对应组件。界面元素选择器将网页元素、源码位置与 AI 对话关联，减少信息整理和工具切换。

## 选中网页元素，一键发起对话

在网页中选中目标元素并填写问题，即可将元素结构、样式、组件信息及可选截图发送给 AI，减少手动整理上下文的工作，并明确分析与修改范围。

![选中网页元素，填写问题并发送到 VS Code 的 Codex 对话](./images/动画1.gif)

目前的一键对话只支持 **VS Code 中的 Codex 插件**。实现思路是通过本机桥接服务，借助 **CDP（Chrome DevTools Protocol）** 连接编辑器中的 Codex 界面，把网页端收集的上下文添加到输入框，或直接发送。也可以只复制提示词，再自行粘贴到对话中。

## 从页面直接定位源码

选中页面元素后，点击源码按钮，可根据 React / Vue 调试信息跳转至 VS Code 中对应的源码位置，减少从页面问题到组件实现的检索步骤。

![选中页面元素，通过源码按钮在 VS Code 中打开对应代码](./images/动画2.gif)

源码定位依赖页面保留的调试信息和项目路径匹配，因此不能保证所有网页都能直接定位，尤其是缺少调试信息的生产页面。

## 将网页结构转换为 Figma 内容

“复制到 Figma”功能源于设计协作需求：团队使用 Axure，但当时相关 MCP 工具较少，难以直接接入后续 AI 工作流。该功能以网页为中间载体，将选中区域的 DOM 结构与样式转换为 Figma 可接收的设计内容。

在网页中选中区域并复制，粘贴至 Figma 后即可编辑文字与图层。转换后的结构化内容便于进一步调整，也可用于后续 Figma 工具协作。

![将网页选区复制到 Figma，粘贴后继续编辑文字和页面内容](./images/动画3.gif)

转换对象为网页当前呈现的内容，并不等同于恢复 Axure 原始组件、交互逻辑或完整设计系统；复杂样式的转换效果仍需要检查。
