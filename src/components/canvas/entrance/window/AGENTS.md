## window

手绘窗户、玻璃裂纹和投掷石头；共享落地运动来自 ../shared/。

**Important:** 每个窗格只接受一次投掷；残留在进门返回后保留，数量与 GPU 资源必须有界。

### Important files

- `PaperWindow.tsx` — 右侧手绘窗户与一次性砸窗交互；管理各窗格破损、落地保留的石头/碎片、窗框震动和减少动态效果偏好。
- `windowFracture.ts` — 根据窗格内命中点生成共享锯齿边界的放射裂纹；每格持有固定数量几何缓冲，首次撞击时填充并将毛边复制到独立几何。
- `sketchStone.ts` — 手绘小石头的不规则棱角几何、灰白纸纹材质和铅笔轮廓；由 `PaperWindow` 创建一次并供三个效果槽共享。

### Implementation notes

- 右侧窗户由 `PaperWindow.tsx` 渲染，窗框和玻璃纹理由 `../door/EntranceDoors.tsx` 批量加载并传入；上方一块横窗、下方两块竖窗。`PANES` 的 1024 像素洞口范围同时推导玻璃 UV、位置、尺寸和命中边界；玻璃图按窗格克隆 offset/repeat，碎片与毛边使用同格材质，克隆纹理在卸载释放。底图纸纹仍独立克隆，不修改共享缓存。
- 点击窗户按命中位置选择窗格：每个完整窗格只接受一次投掷，在石头飞入前立即标记已投掷，拦截同格快速连点；不同完整窗格可以连续点击并同时播放。已破碎或已投掷的窗格再次点击不生成石头、碎片或震动。
- 三个窗格各自拥有一颗石头和 32 块飞散碎片，落地后持续显示，不淡出、不缩小、不回收；16 块毛边残片留在窗沿。`windowFracture.ts` 按传入的矩形尺寸生成裂纹和 UV；窗框与横竖档不接受投掷。破口与地面残留在进门返回后保留，仅刷新/重新挂载时重置。最多三颗石头、96 块落地碎片，不能重新引入重复点击产物或无限增长的效果池。
- 石头采用扁圆且不规则的二十面体细分棱面、灰白纸纹、全粗糙度和少量自发光提亮，配合淡铅笔轮廓与少量棱线，融入入口的手绘纸质风格；不带棒球缝线，不使用光滑球面或强反光材质。颜色纹理与 `NoColorSpace` 的凹凸纹理分别克隆，不能把颜色空间配置写回地面共享纹理；所有石头资源参与首屏预热并由共享资产的 `dispose()` 统一释放。
- 窗户命中面关闭深度写入，事件停止传播；`enabled && canEnter && !isOpen` 才允许点击。悬停保持普通鼠标样式，不设置瞄准光标。开门或离开入口时立即落实已接受点击的破损，并将仍运动的石头/碎片放到最终落地位置；停止震动，保留所有残留，不能写入相机或阻断门的交互。
- 碎片和石头从首次挂载起就参与 `SceneWarmup`，未投掷时隐藏，落地后保持可见但停止逐帧计算。几何缓冲只在首次点击与撞击时更新，运动通过 ref 和 `useFrame` 的 delta 驱动，无逐帧 Three.js 对象创建或 React state 更新。同批碎片共用材质；卸载释放自建几何、材质与克隆纹理，保留 useTexture 共享缓存。
- 每次点击即时读取 `prefers-reduced-motion`；开启时直接显示破口和已落地的石头/碎片，跳过飞行、震动和弹跳。验证须覆盖未撞击前同格连点、不同完整窗格连续投掷、已破窗格不响应、顶点不穿地、落地后长期静止、进门返回保留、触摸与减少动态效果；重复点击后 GPU 资源与残留数量保持稳定。

- `PaperWindowHandle.breakGlass()` 向首页暴露唯一受控操作；与点击共用 `launchStone`，依次选择尚未投掷的窗格，仍遵守交互门禁和一次性预留。返回 started/exhausted/unavailable 供页面如实反馈；不能模拟 DOM 点击或绕过已有碎片上限。

- 玻璃平面位于窗户局部 z=0.015，紧贴 z=0.02 的窗框背面；玻璃及破损暗底尺寸在 PANES 洞口四边各外扩 4/1024×1.5 世界单位，压入窗框内沿以覆盖透视及采样接缝。两者保持不透明并写深度；源纹理、PANES UV/命中区及破碎范围不变，不能通过扩大点击区替代封缝。验证未破损、破损以及门镜头移动中的窗沿。
