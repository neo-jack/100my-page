## shared

窗户石头、玻璃碎片与断花共用的落地入口和碰撞轨迹。

**Important:** 此处只放跨物品共用逻辑；窗格裂纹归 window，花坛布局归 planter。

### Important files

- `windowDebris.ts` — 断花、石头与玻璃碎片共用的落地入口；有花坛时播放碰撞轨迹，无碰撞盒时保留原有地面解析运动。
- `debrisCollision.ts` — 点击时以 120 Hz 预计算有界轨迹，按旋转顶点包围范围处理坛沿、泥土、侧面、地面、轻弹和摩擦；播放、减少动态效果和离场结算共用轨迹末帧。

### Implementation notes

- 碰撞盒使用入口局部坐标，`LandingMotion.offset` 明确记录碎片父组到入口的平移：石头为窗组偏移，玻璃再加窗格与碎片组偏移，断花为种植点偏移。禁止把世界 z 或相机距离混入碰撞盒。旋转时跨越两侧坛沿的大碎片应架在坛沿上；石头接触阴影使用实际支撑面的高度。
- 碰撞轨迹最多 720 步，在点击时写入预分配数组，`useFrame` 只按 delta 播放并在落定后停止；花朵碰撞轮廓从贴图 alpha 取样，不使用透明矩形作为支撑面。减少动态效果与离场结算必须读取同一轨迹终点，不能直接放到地面而穿过花坛。
