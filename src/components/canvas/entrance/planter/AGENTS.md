## planter

两侧实体木槽、泥土、多肉和可折断纸花；布局与碰撞盒共用 planterLayout。

**Important:** 可见几何、泥土落区和碰撞盒必须由同一份布局推导。

### Important files

- `EntrancePlanters.tsx` — 实体木槽、泥土、六株多肉与十枝可点击折断的纸花；花朵弯折后与短茎分离，落下后持续保留。
- `planterLayout.ts` — 两侧花坛在入口局部坐标内的位置、木板、坛沿和泥土尺寸；渲染几何、静态碰撞盒与断花泥土落区 `soilBounds` 的共同事实来源。

### Implementation notes

- 花坛以 `planterLayout.ts` 的同一份布局生成木板、坛沿、泥土和碰撞盒，不可单独调整碰撞高度或改回一整张无厚度的贴图。右花坛中心与窗户同为 `x=2.5`，花枝顶部保留窗下间隙，左右花坛避开门前路径与门的点击面。
- 两侧花坛必须靠墙：`../door/EntranceDoors.tsx` 将实际墙前表面 `wallThickness / 2` 传给布局，后板外表面只留 0.001 世界单位的深度间隙，花坛中心由后板位置加半个坛深推导。后沿只向坛内加宽，避免穿入墙体；花枝、泥土和碰撞盒都跟随布局，不再单独指定离墙的 z 值。
- 新增 `garden-*` 图由 imgaier 以 ref 长条木槽为主参考、现有窗框和门纹理为风格参考生成，资源说明见 `public/textures/entrance/AGENTS.md`；花坛颜色图根据导入 URL 集合识别并设 `SRGBColorSpace`，不能从文件名或 `/garden-` 路径识别，不要修改共享纸纹的颜色空间。花朵按 alpha 命中，透明空白不阻断后方事件，拖动超过 6px 不折花。
- 每枝花只接受一次点击，先弯折 0.18 秒再从花高 19% 处分离；最多保留十枝断花，不复制或重建 GPU 资产。短茎、断花和窗户残留都在进门返回后保留，仅刷新重置。`interactive=false` 时结算已开始的动作并停止悬停；每次点击读取减少动态效果偏好，开启时直接落定。
- 断花朝花坛内侧、沿长边倒下；`soilBounds` 从同一布局扣除坛沿内伸和边缘间隙得到。烘焙轨迹时按旋转后的完整 alpha 轮廓限制 x/z，并以泥土顶面支撑，确保花瓣与断茎落在土上；不能只限制花茎原点或在末帧瞬移。该落区只传给花朵，石头和玻璃保持原碰撞行为。
- 花朵配色由 `EntrancePlanters.tsx` 的 `FLOWER_PALETTES` 维护：柔和暗黄雏菊、灰粉/杏色郁金香和灰紫波斯菊，花心使用暗金色，茎叶与多肉使用低饱和绿。上下段按原贴图 UV 写入线性空间顶点颜色，保留铅笔纹理、原始 alpha 命中和断花后的配色；不要为着色修改共享纹理或逐帧重建几何。
- 花坛验证还需覆盖两侧花朵、透明区域与拖拽不误触、全部花朵连续折断、窗下泥土/内外侧坛沿/侧面碰撞、长碎片跨坛沿、竖屏取景，以及刚折断/投石就进门时的最终姿态；类型检查与构建命令沿用项目根说明。
