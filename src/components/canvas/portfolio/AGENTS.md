## portfolio

`portfolio/` 在 About 云层中渲染“左侧作品卡片 + 右侧技术栈气球”，并独占管理选中作品期间的相机聚焦和返回。

**Important:** 聚焦、阅读及返回全程持有 `lockedRef`；`AboutRoom` 必须暂停滚动积分和飞行姿态，禁止两个动画同时写相机。

### Important files

- `PortfolioField.tsx` — 三组作品的循环分布、卡片封面、左右分散及两段式 GSAP 聚焦动画。
- `TechStackBalloons.tsx` — 方块纸气球的漂浮、悬停彩绘/磁力、点击弹开、名称和重生；沿用 ref About 的交互思路，气球音效服从 AudioProvider 偏好。当前纹理来源及两态配准规则见 `public/textures/about/AGENTS.md`（相对项目根目录）。
- `balloonRaycast.ts` — 缓存素描贴图 alpha，按 UV 过滤平面射线命中；透明区域穿透到后方气球，悬停和点击共用轮廓，不随上色动画变化。排除禁用、弹开和祖先隐藏的气球。
- `../../../data/note/` — 共享作品数据与交互阶段类型；Canvas 不维护文案副本。

### Implementation notes

- 先将卡片转正，再推进和平移相机，为桌面靠近卡片的 DOM 详情留空间；相机距离按 FOV、宽高比和卡片占屏比例计算。移动端详情打开后隐藏当前作品整组，但保留挂载和世界坐标供镜头聚焦、返回使用；聚焦动画期间仍保留卡片，避免详情出现前突然留白。
- 选中前保存相机位置、四元数及卡片的旋转和显现进度，冻结整组左右分散位置。关闭后恢复浏览进度，再释放滚动锁；聚焦距离要乘实际世界缩放，保证移动端正常。
- `isReturningHome=true` 或 `enabled=false` 时立即终止聚焦/返回 timeline、复原卡片并清空 session、阶段和滚动锁，不再恢复旧飞行镜头；首页相机由 `EntranceDoors` 接管，避免旧动画把镜头拉回走廊。倒退期间 `enabled` 保持开启，让作品随相机距离自然散开/淡去；用独立的 `interactive=false` 禁止卡片与气球交互，关门完成后才关闭 `enabled`。
- 漂浮时间在锁定期间暂停，循环区块不回收；位移使用 About 传入的滚动 ref，循环更新只在周期边界触发 React state。
- 作品按 40 单位纵向间距成组出场；每组卡片在左、技术栈气球在右，不能把三个作品横排。窄屏等比缩小整组，继续保持左右布局。
- 作品数量来自 Markdown 清单；清空作品时循环长度保留一个间距作为下限，避免滚动除零，场景内不产生卡片。
- 队列起点由 `INITIAL_ROUTE_OFFSET=18` 控制；入场相机停在世界 `z=-19.1` 时首组距镜头 23.9 单位，处于渐入范围内，无需滚动即可在远处看到作品和气球。后续作品和循环副本共用该偏移，保持间距；调整时避免首组落到渐入范围外或上一周期末组进入初始视野。
- 靠近时参考 ref About 的平方缓动：距镜头 14→3 单位，卡片向左、气球向右各移动最多 12 单位，气球内部略微散开；向后滚动自然合拢。保留卡片尺寸，不再向上收缩、抬高或固定屏幕中心。
- 参考 `ref` About 的距离连续插值思路：32→18 单位范围渐入，并使用帧率无关的阻尼平滑透明度；不能改回按距离阈值直接显现。
- 整组散出视野后再淡去；纸面、边框、插图、文字和气球共用显现进度，不能按距离阈值突然出现或留下轮廓。透明点击层保留零透明度。
- 渐入材质关闭深度写入，完整中文卡面→按钮彩色层→按钮揭示层按 `renderOrder` 排序；卡片材质保留各自原始透明度乘以统一进度，气球 Troika 文字仍通过 `fillOpacity` 更新。
- 交互排除超过 6px 的拖动；滚动期间消失的卡片不能点击；作品通过场景中的卡片打开，不提供底部作品选择栏。
- 作品卡片的选择事件绑定在整张卡片组上，透明平面覆盖完整卡面（包括按钮区域）作为命中层；点击卡片任意位置都进入镜头聚焦流程。
- 卡片使用 imgaier 生成的完整中文 WebP 纹理，纸纹、边框、标题、插图、分类与按钮文字均在图内；不再叠加英文 Text 或旧 SVG 插图。卡面比例约 13:17，对应 3.9×5.1 平面，透明点击层不写深度。
- 按钮两层从卡面克隆纹理并通过 UV 取样，保持中文文字一致；底层使用暖色 tint `#ecd5a6`，三张生成卡面在 `BUTTON_LAYOUTS` 中分别校正：01 `2.88×0.45, y=-2.01`，02 `2.93×0.47, y=-2.05`，03 `2.92×0.53, y=-1.95`，避免着色范围上下或左右偏移，揭示层保留悬停动画。按钮宽度、尺寸和位置必须与对应生成卡面按钮区域一致；只释放自行克隆的纹理，不释放 `useTexture` 共享缓存。
- `prefers-reduced-motion` 禁用持续漂浮并缩短聚焦/返回动画；卸载时终止 timeline 并恢复相机。
- 气球与名称 Text 在首次挂载时预加载并参与 SceneWarmup，点击不能再下载字体；气球通过数据映射的 `sketch` / `painted` URL 加载，字体和弹开音效也使用静态导入；触摸设备复用素描图，悬停上色使用现有 RevealBasicMaterial。pop/hover timeline 在卸载时清理。
- 气球使用轻微复合水平摆动及相位调制升降，继续由共享 `timeRef` 在作品聚焦时冻结。悬停放大 1.048，上色/复原为 0.78/0.48 秒，指针偏移上限 0.145；爆破音效为 `public/sounds/paper-pop.mp3`，保持静音偏好、空间衰减、弹开和重生流程。
- 气球命中只接受素描 alpha ≥32 的像素，不能依赖材质透明度或矩形平面直接拾取；贴图须可供同源 Canvas 读取。交互失效时清除悬停，指针移动持续阻止事件穿透已命中的前景气球。

- BUTTON_LAYOUTS 按笔记 ID（A1react、A2design、A3context）匹配卡面按钮区域；目录重命名时同步这些键，封面文件名无需随 ID 改名。
