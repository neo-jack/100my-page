## about

`about/` 负责纸飞机、天空、云朵及作品场景的飞行控制。场景由 `HomePage.tsx` 始终挂载在入口门后，`hasEntered` 控制进入后的交互；漂浮作品由相邻 `portfolio/` 渲染。

**Important:** 房间组固定在 `z=-25`；滚动进度通过 ref 传给子组件，由子组件计算世界坐标。不要把滚动状态改成触发整棵 React 树重渲染的 state，也不要用入口门覆盖门后场景。

### Important files

- `AboutRoom.tsx` — 场景入口，管理滚轮/单指触摸输入、滚动惯性、相机飞行姿态、作品阶段传递和状态重置。
- `InfiniteSkyManager.jsx` — 根据滚动位置回收云朵区块，持有并释放固定的共享云纹理池，不再渲染头像、奖项、浮岛或技能气球。
- `../portfolio/PortfolioField.tsx` — 漂浮作品卡片、聚焦与返回相机控制，细则见该目录说明。
- `SkyChunk.tsx` — 使用固定种子生成可复现云朵分布，并处理漂移、闪避、广告牌和世界空间剪裁。
- `cloudField.ts` — 地址化整数采样、分层云场、连续风场和 Canvas 纸纹云形；不依赖历史云图或索引宽高比表。
- `PaperAirplane.tsx` — 纸飞机组件、纸面材质与内部折痕线，外缘不描线。
- `paperAirplaneModel.ts` — 参照 `100my-page/res/image.png` 的宽三角翼、下折尾部、薄纸封边和固定种子铅笔纹理；参考图不作为运行时依赖。

### Implementation notes

- 世界坐标按 `ROOM_Z + scrollProgress + localZ` 计算；云朵与作品卡片各自用 `visible` 控制可见范围。
- 滚轮和触摸输入先转成速度冲量，再由帧率无关的指数摩擦力衰减；保持 `scrollPosition` 和 `scrollVelocity` 为 ref，避免输入过程触发 React 树重渲染。
- `hasEntered` 切换时清空滚动位置、惯性、累计提示距离和飞行倾斜，并恢复纸飞机可见性与基础姿态；`isReturningHome=true` 时只停止输入、惯性和飞行姿态写入，保留云层/作品的滚动位置及纸飞机状态，直到关门完成再重置。返回镜头由 `EntranceDoors` 独占，About 不得在倒退过程中重置场景或写相机。
- `AboutRoom` 在累计实际 `scrollPosition` 移动距离达到约 1.8 个场景单位后调用一次 `onFlightDistanceReached`，由 DOM 层移除飞行纸条提示；达到阈值前通过 `onFlightHintProgress` 回传归一化累计距离，DOM 使用 ref 渐隐，不逐帧更新 React state；首次输入但未达到距离时仍保留提示，来回移动也会累计，回到入口重新进入时重置。
- `AboutRoom` 接收 `hasEntered`、选中作品 ID、作品阶段、选择回调和阶段回调；门动画结束后接管飞行，作品聚焦期间通过共享 ref 让出相机控制，并把详情打开阶段传给作品场景以切换移动端封面可见性。
- 纸飞机外层组从首次挂载起就使用 `AIRPLANE_BASE_PITCH` 的 0.105 弧度抬头姿态，进入后的俯仰在同一基准上叠加；不要等 `hasEntered` 变为 `true` 才设置基础角度，避免转场结束时突然抬头。
- 飞行姿态以 41.5 单位独立周期运行，使用小幅复合横滚和相位调制俯仰；启动阈值为绝对距离 0.52，之后在 4.9 单位内渐入。正反向都从零渐入；保留指数平滑与基础四元数乘法顺序。
- `PaperAirplane` 朝向局部 -Z，翼展 2.6、纸厚 0.009；两片三角主翼连接中央折脊和向下弯收的尾缘。上下表面、封边和内部折痕均由 `paperAirplaneModel.ts` 的同一组控制点生成，调整轮廓时保持一致。
- `AboutRoom` 的纸飞机默认缩放 0.8，窄竖屏按 `min(0.8, aspect × 1.8)` 收缩翼展，为横滚留出边距；保留原前景位置和基础俯仰，不用改变相机去适配模型。
- 纸面使用浅色 `MeshBasicMaterial`、分面顶点色与单张 1024px 程序化纸纹；不依赖场景光照，不把参考图作为平面贴片。外轮廓保留自然纸面边缘，不叠加黑色描边；仅内部真实折痕由 Drei `Line` 绘制，不自动描出三角剖分边。组件卸载时释放自建几何体和纹理，飞行帧内不重建资源。
- 无限云层管理器只保留当前视野附近的区块；作品卡片由 `PortfolioField` 独立管理循环周期。
- `InfiniteSkyManager` 每帧将云层父组的 `position.z` 设为滚动进度；`SkyChunk` 保留区块局部坐标，并将同一进度用于世界空间剪裁和闪避。不能只更新区块编号或剪裁坐标而漏掉父组位移，也不能在父子两层重复位移。
- 卡片的纸面、封面、按钮及右侧技术栈气球在首次挂载时批量加载。旧奖项/完整 Skills 里程碑不挂载；气球纹理由 `portfolio/TechStackBalloons.tsx` 按作品技术栈使用。
- 首页揭幕前由上级 `SceneWarmup` 等待全部文字字形并预渲染隐藏卡片；不要增加进入后才触发的懒加载或独立 `fallback={null}` 边界。
- 动画循环不得在每帧创建 `Euler`、`Quaternion`、`Vector3` 等临时对象；云朵硬剪裁使用 `visible`，不要用零透明度继续提交绘制。
- 云形由 `cloudField.ts` 的 `loadCloudCanvases()` 生成固定 8 种手绘变体，每张 512×256；使用逻辑 1024×512 坐标保持排线比例，联合轮廓内保留体积高光、下部阴影和纸纹。各云种子只选择纹理索引，平面宽高仍独立采样；不再引用 `public/textures/clouds` 的历史贴图。
- `InfiniteSkyManager` 挂载时创建 8 张共享 `CanvasTexture`（sRGB、默认 mipmap，RGBA 含 mipmap 估算合计约 5.33 MiB），传给所有区块；`SkyChunk` 仅通过材质 `map` 引用。区块切换不得创建 Canvas、重绘纹理或重新上传；不要恢复每朵独立 1024px 纹理。共享池由管理器卸载时统一 dispose，单朵云或区块卸载不能释放共享纹理，首次 GPU 上传沿用 `SceneWarmup`。
- 云层性能验证需跨多个区块往返，核对纹理对象始终复用同一组 8 张、Canvas 创建不随滚动增加、GPU 纹理数量不持续增长；同时检查近景笔触、透明边缘和深度遮挡。不能以静态纹理预览或类型检查代替连续飞行验证。
- 云区块长度 41，裁剪位置 -8.2；`InfiniteSkyManager` 从 `SkyChunk` 导入区块长度。每块按三个纵深带、左右两侧分为六格，各格固定 2 朵，并以 15% 概率增加第 3 朵，共 12–18 朵、平均约 12.9 朵；使用按属性寻址的整数哈希保持往返分布一致。相机周期独立于区块回收。
- 漂移采用连续世界纵深上的平滑值噪声风场，与有效场景时间关联，邻近云共享风势；接近时按云宽和原始横坐标让出走廊。云面朝向相机并叠加小幅固定纸片倾斜，不使用旧的左右 60 度偏转。
- 天空场景完全关闭风声，`AboutRoom` 不导入或挂载风声音频；加载、门外与进门后均不播放。背景音乐和气球音效由各自消费者控制。
- 透明贴图平面和天空兜底平面保持正确深度写入。
- 聚焦、阅读和返回期间清零滚动速度、暂停飞行姿态并隐藏前景纸飞机；返回完成再恢复。DOM 按钮、导航和详情内的滚轮/触摸不产生飞行冲量。

- 纸飞机纸纹通过 loadPaperCanvas 的共享 Promise 分段异步绘制，PaperAirplane 用 React use 纳入现有 Suspense/预热门禁；固定种子、1024px、纸纹点与排线顺序保持不变。只缓存 CPU Canvas，组件仍独立创建和释放 GPU Texture，不要在 render/useMemo 中重新执行完整纸纹绘制。

- 云纹理 CPU Canvas 同样通过共享 Promise 逐张生成并纳入 Suspense，避免挂载重试反复绘制；每个管理器仍独立拥有 8 张 GPU Texture，卸载只释放自己的纹理。
