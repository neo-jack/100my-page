## shared

工程优化条目与宠物架构说明共用的纸张详情 dialog，内容和选择状态由调用方传入。

**Important:** 保留原生 dialog 的焦点隔离、Esc 和关闭后的焦点恢复。

### Important files

- `PaperDetails.tsx` — 工程优化条目的通用纸张详情 dialog；由 `../scroll/EngineeringNotes.tsx` 传入内容并处理关闭。
- `NoteMarkdown.tsx` — 工程与作品共用的 Markdown 阅读器，支持 GFM、代码、表格、图片及视频；AI 聊天仍使用 pet 中带协议卡片的独立渲染器。
- `NoteImage.tsx` — 文章图片的可键盘触发缩略图与全屏预览，支持适应屏幕和原尺寸滚动查看。

### Implementation notes

- 文章图片点击后通过 portal 将原生 modal dialog 挂到 body，在已有详情 dialog 之上显示，避开纸张裁剪与变换；关闭按钮、背景点击及 Esc 只关闭图片，阻止事件传播到外层详情，关闭后恢复缩略图焦点。默认适应屏幕，可切换原尺寸并滚动查看，视频继续使用原播放器。卸载时关闭预览，不遗留顶层模态。

- Markdown 普通正文段落使用 `text-indent: 2em` 实现首行两汉字缩进，不向内容文件写入空格；按钮组、按钮文字及包含图片/视频的段落不缩进。

- 正文预览按钮背景静态导入 `public/textures/portfolio/preview-button.webp`，为 imgaier 生成的无字纸纹双线边框；原图边框仅占中央约 27% 高度，背景居中按 `100% 360%` 显示，使可见边框贴近按钮上下边缘。按钮使用 `min-h-8 py-0.5`，避免图片留白和内边距扩大视觉间隔。经灰度、提亮和对比度滤镜淡化原图纸底，再以 multiply 融入详情皱纸。链接不能设置 `isolate` 或独立底色，否则会阻止混合并重新出现矩形色块；悬停和聚焦仅加深边框与文字。文字由 DOM 渲染，不再叠加 CSS 模拟边框。替换图像时同步核对留白、文字安全区及 public 完整性基线。

- `NoteMarkdown.tsx` 将 title 为 `preview`，或纯文本以“在线预览”“预览”“探索作品”开头并后接冒号、空白或结束的链接渲染为全宽手绘边框按钮；仍使用原生链接、新标签页与可见键盘焦点，普通链接保留下划线。按钮标记和写法维护在 `data/note/README.md`，不新增固定底部按钮。
- 仅包含链接与空白/换行的 Markdown 段落自动渲染为纵向按钮组，支持任意数量、任意文字的链接，无需 `preview` 标记；组内固定间距 4px，软/硬换行及尾随空白不增加间距。按钮使用块级 flex、不加上下外边距；组外间距沿用段落样式，混合正文中的普通链接保留下划线。

- 工程优化详情复用作品详情的纸纹，使用撕边、保持水平的居中纸张，不设置静态倾斜或旋转动画；入场仅淡入并向上平移，遵守减少动态效果偏好。原生 dialog 隔离背景，支持关闭按钮、Esc 和点击外侧关闭，关闭后恢复触发按钮焦点；内容区可滚动并参与键盘焦点循环。
- 标题直接位于纸张顶部，与关闭按钮同排；下方为 Markdown 正文，不显示编号、分类、独立摘要、技术标签或固定底部按钮。dialog 通过标题提供可访问名称，不引用已移除的摘要节点。
- Markdown 正文与标题由 `data/note/` 提供；首页 AI 架构说明以同样的 `id/title/body` 对象传入 `PaperDetails`，不维护 description/highlights 或底部按钮字段。
- 依赖原生模态 dialog 的焦点约束，不用只枚举按钮/链接的手写 Tab 循环，以免跳过 Markdown 视频原生控制条。代码块、表格和正文区可单独滚动，图片响应式，视频仅预载 metadata、不自动播放，正文不解析原始 HTML。

- Markdown 链接 title 为 `download:<文件名.js|md>` 且 href 为同源绝对路径时使用原生 `download` 属性，恢复文件名且不打开新标签；下载链接沿用现有按钮组样式。外部链接不启用下载，普通预览行为保持不变。

- 笔记文字颜色统一在 `NoteMarkdown.tsx` 维护：正文使用深灰绿 `#454b40`，引用 `#59604f`，按钮文字 `#454b3d`，普通链接 `#365e70`；工程、作品及独立说明共用，不在 Markdown 内容中逐篇设置颜色。
