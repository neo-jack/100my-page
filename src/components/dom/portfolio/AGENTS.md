## portfolio

Canvas 作品卡片对应的响应式纸张详情，选择和聚焦阶段由首页协调。

**Important:** 等待镜头聚焦完成后显示详情，关闭时保持镜头返回与 dialog 生命周期同步。

### Important files

- `PortfolioDetails.tsx` — 原生模态 dialog 与响应式纸张详情；数据来自 `../../../data/note/`，作品通过 Canvas 卡片打开。

### Implementation notes

- 作品数据共用 `data/note/`；首页仅维护选择与交互阶段，Canvas 负责动画，DOM 负责中文内容与链接，不引入虚构接口或路由。
- 标题直接位于纸张顶部，与关闭按钮同排；下方通过 `../shared/NoteMarkdown.tsx` 渲染正文，不显示编号、分类、独立摘要、技术标签或固定底部按钮。标题与正文来自同篇 Markdown；实际作品链接可写入正文，媒体与键盘规则见 shared/AGENTS.md。
- 打开详情时将正文滚动复位；退出阅读阶段暂停正文视频，防止返回场景后后台继续播放。作品清单为空时不渲染详情。
- 正文滚动条使用细窄灰绿色滑块和透明轨道，露出父级纸张纹理；保留稳定滚动槽及正文右侧间距，不恢复系统默认白色轨道。
- 详情在镜头聚焦完成后显示；桌面靠近左侧作品卡片，移动端从顶部导航下方铺开并允许内部滚动。移动端详情打开时由 Canvas 隐藏当前作品卡片，避免封面与详情叠放。关闭、Esc 或点击外侧触发镜头返回，返回完成后关闭 dialog。
- 详情纸张始终保持水平，不设置静态倾斜或旋转动画；入场仅淡入并向上平移，退场仅淡出并向下平移，遵守减少动态效果偏好。
- 桌面详情纸张使用 `left: clamp(26rem, 45vw, 44rem)`，在作品卡片右侧保留更宽的明确空隙；移动端仍由 `max-md:inset-x-4` 铺满可用宽度，不继承桌面偏移。
- 聚焦过程中不显示可见提示或取消按钮，保留 Esc 取消与屏幕阅读器状态播报；详情打开时使用原生 dialog 限制焦点与背景交互，不使用空链接跳转。
