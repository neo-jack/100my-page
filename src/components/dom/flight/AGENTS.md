## flight

桌面进入天空后的纸条操作提示，显示、距离渐隐与当次关闭状态由首页协调。

**Important:** 提示保持点击穿透；透明度跟随实际飞行距离，不使用计时器或原始输入次数关闭。

### Important files

- `FlightGestureHint.tsx` — 复用入口探索提示的纸纹和锯齿边缘，独立设置响应式字号；通过 React 19 的 ref prop 将纸条元素交给首页更新透明度。

### Implementation notes

- 仅桌面在开门完成、作品阶段空闲且未选择作品时显示“滚动鼠标滚轮，向前或向后飞行”；宽度 ≤600px 或主指针为触摸且无悬停时完全不挂载提示，手机横屏同样隐藏。不再使用鼠标和手指 SVG 循环动画。
- `AboutRoom` 将累计实际移动距离归一化为 0–1 进度，`HomePage` 通过 ref 更新纸条透明度为 `1 - progress`，避免逐帧更新 React state。暂停移动时保留透明度，往返移动继续累计；作品详情关闭后重新挂载时恢复当前透明度，重新进门时重置进度。
- 累计实际移动达到 1.8 个场景单位后关闭；每次进门都重置关闭状态和渐隐进度，刷新或重新打开后仍显示。不读写旧的 `3dpage:flight-hint-dismissed` 标记。验证桌面文案与手机不显示、移动中渐隐、静止保持、达标隐藏、返回再进门及刷新后重新显示。
- 纸条使用原始 floor_paper 纹理，最大宽 28rem，桌面正文 0.975rem、标题 1.0875rem；底部留白和视口边距与首页探索纸条一致，布局与样式直接写在 JSX 上。
