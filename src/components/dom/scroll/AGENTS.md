## scroll

保留的卷轴组件、工程优化条目与详情选择；共用纸张 dialog 来自 ../shared/。当前首页已移除卷轴，不挂载本目录组件，也不等待其资源；以下交互规则仅描述保留组件。

**Important:** 卷轴装饰、文字和详情保持分层；图像解码参与首页就绪条件。

### Important files

- `EngineeringNotes.tsx` — 首屏工程优化按钮及详情选择状态；条目数据来自 `../../../data/note/`，点击打开居中纸张详情。
- `EngineeringScroll.tsx` — 首屏悬挂卷轴、受控展开/收起状态与资源解码；样式直接维护在对应 JSX 元素的 Tailwind `className` 和 `style` 中，状态类由 `expanded` 切换；不维护独立 CSS 文件、样式字符串或 `<style>` 标签。纸面承载工程优化条目。

### Implementation notes

- `EngineeringScroll` 通过入口 Canvas 内不启用 transform/distanceFactor 的 `Html` 固定于左侧墙面：初始悬挂短卷轴，显示“3D 前端工程设计”与下轴居中的向下箭头，展开后箭头向上，不显示展开/收起提示文字；按钮通过 `aria-label` 描述操作。点击整幅收起的卷轴后，下轴随纸面向下展开，上轴、下轴保持各自比例，不绘制挂绳。卷轴挂点位置和角度固定，由 Canvas 投影挂点位置，正文按屏幕原生像素绘制，不在悬停时摇摆；展开只向挂点下方延伸，使用九宫格 `border-image` 和 `0fr → 1fr` 的内容高度过渡，不缩放文字或整幅图片。展开后点击标题或在卷轴内按 Esc 收起；收起区域设 `inert` 和 `aria-hidden`，不能参与键盘焦点。详情 dialog 打开时 Esc 仅关闭详情。开门和返回关门期间保持墙面卷轴可见并保留展开状态，交互用 inert 禁用；相机越过墙面后由 Html 自然隐藏，入口 enabled=false 时才卸载 DOM；900px 及以下隐藏，不再用屏幕固定弹层替代墙面卷轴；手机模式重置卷轴。展开状态由 HomePage 统一传入。
- 卷轴世界宽 1.52，入口组件将投影宽度取整为 --scroll-width；标题、条目、页脚分别按该宽度的 0.07/0.065/0.055 原生字号绘制，常规桌面约 200px/14px/13px/11px；不对整块 DOM 进行 scale 或 matrix3d 透视缩放，避免字形被缩小重采样。标题字重 600、颜色 `#41443f`。装饰层复用挂板灰色纸纹，使用灰度、`brightness(1.04)` 和 `1px 2px 1px / 8%` 的轻微投影，装饰层保持 opacity=1；纸面不透出墙纹，保留低对比卷边，避免亮白高光。滤镜仅作用于装饰层，不能影响文字或 dialog。
- 卷轴不显示“本页面”角标或非 Demo 说明；展开后在 `EngineeringNotes` 列表下方、卷轴内容的右下角显示右对齐灰色小字“点击条目查看优化详情”，提示与列表间距由提示段落的上边距控制，收起时随内容隐藏。五项一级工程优化方向为性能优化、CDN 优化、SEO 优化、前端监控、CI/CD 流水线，条目均带短横线前缀，无嵌套子条目。条目使用 `#41443f`，按钮在悬停、键盘聚焦、按下或展开时显示紧凑的点状描边（水平外扩 `0.25rem`、垂直外扩 `0.125rem`），避免相邻条目的方框重叠。仅按钮和弹窗启用指针交互，其余首屏文字保持点击穿透。
- 卷轴 `picture` 与 CSS 复用 从 `public/textures/engineering/hanging-scroll.svg` 导入的同一 URL，图片解码后设置 `engineeringScrollReady`；仅恢复挂载时才应将卷轴资源解码纳入首页揭幕条件。窄屏 `picture` 使用透明占位图，不下载隐藏的卷轴资源；图像报错走现有加载失败流程。验证展开/收起、下轴点击、全部条目详情、Esc 与焦点恢复、窄屏不请求资源、减少动态效果及返回主页后的复位。
- 下轴始终覆盖透明原生按钮 `engineering-scroll__bottom-toggle`，点击或键盘激活均切换展开/收起状态，收起时将焦点恢复到标题按钮；点击区域与居中箭头随下轴位于纸张底部，不增加可见按钮边框、不触发卷轴倾斜或位移。箭头为装饰性 SVG，通过 `expanded` 旋转切换方向，减少动态效果时停用旋转过渡；按钮的 `aria-label`、`aria-expanded` 与状态同步。

- 外层仅横向平移半宽，上轴顶端直接对齐 Canvas 投影锚点，投影坐标取整以避免小数像素平移；不能因展开后的高度变化上移挂点。详情继续使用原生 modal dialog 顶层，须验证它不受墙面透视缩放影响。
